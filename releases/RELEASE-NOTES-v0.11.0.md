# 声间 AudioSwitch v0.11.0

本次更新新增软件内更新、开机自启、必要文件检查与修复，并提供可直接下载运行的 EXE。日常启动、升级和程序搬家更方便，原有设备优先级、白名单、音量及音效预设继续保留。

## 新增功能

- **软件内更新**：在主面板点击“检查更新”，查看新版说明后选择“下载并更新”。仅安装官方正式版本，不自动降级；平时不在后台自动检查更新，也不新增常驻更新服务。
- **开机自启**：新增当前 Windows 用户的自启开关，默认关闭。开启后，登录 Windows 时只启动托盘后台，不弹出管理面板，无需管理员权限。
- **文件检查与修复**：启动时检查必要运行文件，也可从主面板点击“文件检查”。运行配置和 SVCL 缺失或损坏时，可从内置副本离线恢复；主程序异常时尝试下载同版本官方包修复，不会借此自动升级或降级。
- **直接下载 EXE**：除完整 ZIP 外，新增 `AudioSwitch.exe` 附件。首次运行会在所在目录释放必要配套文件，无需手动准备运行配置和 SVCL。

## 改进

- 更新包下载后核对 SHA-256、版本和文件内容，校验不通过时停止安装。更新前备份旧文件，写入失败时尝试恢复，并明确报告恢复结果。
- 改善 GitHub 接口限流时的更新检查，优先查看正式发布页；本地版本高于最新正式版时，会分别显示两个版本。
- 程序搬家后提示自启登记的旧路径与处理办法；从新位置启动时，若旧位置的后台仍在运行，会提示先退出旧后台。
- 帮助、说明或许可文件缺失不再阻止程序启动；正常发布包仍保留这些文件。单 EXE 内也已嵌入许可，可用 `AudioSwitch.exe --licenses` 查看。

## 下载与运行

适用于 **Windows 10 / 11 x64**，需要 **.NET Framework 4.8**。

| 附件 | 使用方法 |
| --- | --- |
| `AudioSwitch-v0.11.0-win-x64.zip` | 推荐下载。完整解压到可写文件夹，再运行 `AudioSwitch.exe`。 |
| `AudioSwitch.exe` | 下载到可写文件夹直接运行。保留原文件名，首次运行会生成必要配套文件，因此运行后目录中会有多个文件。 |

## 从旧版升级

**v0.10.1 没有软件内更新入口，需要手动升级到 v0.11.0。**

1. 在旧版托盘菜单中选择“退出”。
2. 下载本次发布的完整 ZIP，解压到准备使用的程序目录，再启动 `AudioSwitch.exe`。
3. 已有音频设置会从原配置位置读取，无需重新配置。如果换了程序目录并希望开机启动，请在新位置重新开启“开机自启”。

后续正式版本可以通过软件内的“检查更新”安装。更新和文件修复不替换个人音频配置；重启后仍会执行你已有的设备优先级和 Dolby 方案规则。
