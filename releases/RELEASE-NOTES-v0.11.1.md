# 声间 AudioSwitch v0.11.1

本次更新新增游戏模式和自动更新流程：空闲时下载，下次启动时安装。同时调整更新设置的位置，并为下载的 EXE 加上居中显示的声间图标。

**升级提醒：自动更新默认开启，包括从旧版升级后首次读取没有该字段的配置。** 如果希望保持手动更新，可在“检查更新”窗口关闭“自动更新”。

## 新增功能

- **游戏模式**：可从主面板左侧或托盘菜单开启，设置会保存。开启后暂停自动更新检查、下载和负载检测，也暂不在下次启动时安装已下载版本；手动检查更新和文件检查仍可使用。
- **游戏模式下减少自动处理频率**：保留设备识别、优先级、白名单和 Dolby 跟随，降低短时间内设备通知的处理频率及界面刷新频率。自动响应可能多等几百毫秒，点击操作仍立即发送。此功能不代表已经测得游戏帧率提升。
- **静默检查与空闲下载**：允许自动更新时，每次托盘真正启动会检查正式版本；发现新版只在主面板提示，不主动弹窗。连续两分钟无键鼠操作、没有待处理音频任务且负载条件合适时，才开始后台下载。
- **避让全屏与高负载**：检测到全屏窗口、较高的 CPU／GPU／磁盘负载或内存紧张时，暂缓或取消本次后台下载，空闲后重试。检测为低频采样，不保证瞬间暂停；没有下载任务时停止负载检测。
- **下次启动安装**：下载并校验完成后，等待下次真正启动再安装，不在使用过程中主动重启。关闭主面板不等于退出，请从托盘退出后重新启动，或等待下次登录自启。安装前重新核验文件并备份旧版。

## 改进与修复

- 自动更新开关集中到“检查更新”窗口，游戏模式位于主面板左侧、深色模式上方；优化小窗口布局，并保留托盘游戏模式入口。
- 关闭自动更新后，停止自动检查、下载、负载检测和下次启动安装，保留已下载文件与手动更新入口。退出游戏模式不会重新开启你明确关闭的自动更新。
- 自动下载重试复用任务目录和已校验的完整包，减少重复占用空间；更新缓存及旧版备份达到预留上限时停止写入并提示手动整理，不自动清理已有备份。
- 修正声间 Logo 的居中显示，并把多尺寸图标嵌入发布 EXE，让文件、窗口和托盘沿用统一图标。
- 修复较深的发布构建目录可能触发自动更新测试路径过长的问题，提升发布构建的稳定性。

## 下载与升级

适用于 **Windows 10 / 11 x64**，需要 **.NET Framework 4.8**。

| 附件 | 使用方法 |
| --- | --- |
| `AudioSwitch-v0.11.1-win-x64.zip` | 推荐下载。完整解压到可写文件夹，再运行 `AudioSwitch.exe`；软件内更新也使用此包。 |
| `AudioSwitch.exe` | 下载到可写文件夹直接运行，保留原文件名；首次运行会释放必要配套文件。 |

- **v0.11.0 用户**：本次正式 Release 发布后，可在旧版中点击“检查更新”并选择“下载并更新”。安装 v0.11.1 后，后续版本才支持上述自动检查、空闲下载和下次启动安装流程。
- **v0.10.1 用户**：请先从托盘退出旧版，再下载并解压本次完整 ZIP，手动启动新版。
- 升级沿用原有设备排序、白名单和音效预设，不替换个人音频配置；重启后仍会执行你已开启的启动优先级与 Dolby 方案。
- 如果移动了程序目录并希望登录时启动，请在新位置重新设置“开机自启”。自动更新和游戏模式设置随配置保存及导入导出；新字段可能不被旧版本识别，计划回退前请先导出旧版配置。
