# 第二阶段：桌面窗口与只读状态

## 实施清单

- 独立 Tauri 2 窗口，1100×740，最小 980×680；保留原蓝灰主题。
- Rust 根据当前 Windows 用户 SID 和会话 ID 连接现有命名管道，只发送固定 `snapshot` 请求。不给网页提供任意请求、管道路径、进程启动或文件读写入口。
- UTF-8 换行协议、连接和响应超时、响应大小上限；并发读取合并／串行，窗口退出后不保留后台任务。
- 前端适配真实快照，保留端点 ID、角色 0/1/2、离线设备顺序与预设的 null 语义；不猜测设备接口类型或空间音效支持情况。
- 桌面模式明确显示只读，禁用设备切换、保存、排序及后台设置；主题只在当前窗口预览。
- 启动／手动刷新／窗口重新获得焦点时读取缓存快照；不增加周期性设备或 Dolby 轮询，不自动启动现有后台。
- 没有后台或连接中断时清除过期设备显示并提供重试。
- 浏览器继续使用独立模拟数据，不借用 HTTP 服务连接本机音频。
- 验证：前端映射与只读限制，Rust 管道协议（中文、断线、超时、超限），桌面构建及窗口关闭后的本应用进程退出。

## 边界

不修改现有后台、配置格式、启动入口或发布包；不执行真实音频写入。不自动提交、发布或合并。阶段完成后汇报并等待验收。

## 进程与内存

Windows x64，WebView2 153.0.4234.48；正常 release 运行、不带调试器，打开约半分钟后采样。原始记录为 `output/desktop/lifecycle.json`。

| --- | --- | --- |
| 打开前 | 1 个后台，工作集约 52.6 MiB / 私有提交约 35.1 MiB | 0 个 |
| 打开后 | 1 个后台，约 52.6 / 35.1 MiB | 7 个进程，工作集合计约 382.7 MiB / 私有提交合计约 195.4 MiB |
| 正常关闭 3 秒后 | 同一个后台，约 52.6 / 35.1 MiB | 0 个，本次 7 个进程全部退出 |

新面板主进程本身工作集约 27.3 MiB / 私有提交约 6.0 MiB，其余来自 WebView2。工作集求和可能重复计算共享页；私有提交不是物理内存占用，不能直接当任务管理器某一列。这里只是本机一次采样，不承诺其他机器的固定占用。带调试器的一次正常关闭也已确认无残留；没有强制杀进程。

关闭后不新增常驻界面进程的目标已验证；打开期间的 WebView2 占用仍需在后续优化与发布验收中关注。

## 重跑和人工验收

1. 按 README 构建。原版后台由用户正常打开，避免测试擅自触发其启动自动应用规则。
2. `scripts/desktop-lifecycle.ps1 -Command Open -DebugBrowser` 只为本次面板临时启用 127.0.0.1:9223 调试端口。检查本机 `/json/version` 后，用 Playwright CLI `attach --cdp` 连接返回的 WebSocket 地址，先读 snapshot，再运行 `scripts/verify-desktop.js`。正常启动不启用端口。
3. CLI detach 后执行 `-Command Sample`、`-Command Close`；脚本按可执行路径、PID、启动时间核对，只发送正常窗口关闭，不停止原版后台。记录先前子进程是否全部退出。
4. 不加 `-DebugBrowser` 重跑 Open / Sample / Close，采样不带调试器的占用。脚本不删除配置、缓存或任何目录。
5. 用户可在原版后台自行退出后点击新面板“刷新状态”，检查无后台提示，再重新打开原版后台并重试。自动测试仅做断线响应注入与独立测试管道，不替代这项完整人工退出／重连。
