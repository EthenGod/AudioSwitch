# 第五阶段：发布兼容与替换实施清单

2026-10-08：仅为下一阶段准备，尚未开始实施。每个独立小项完成后汇报并等待确认；不自动提交、合并、发布或替换日常 bin。第四阶段剩余实机验收继续单列，见 [STAGE-4.md](STAGE-4.md)。

## 已核对的现状

- `release.ps1` 和 `AppUpdate.Files` 固定 8 个文件；旧更新器拒绝文件数量不同的 ZIP。直接加入新面板会使旧版升级失败。
- `FileIntegrity.RequiredFiles` 目前只检查 3 个运行文件。`build.ps1` 将配套文件清单及修复副本嵌入后台；新面板尚未纳入检查或恢复。
- `UpdateInstaller` 按固定清单备份、替换和回滚，必须同步考虑新面板、提示及其子进程，不能只更改打包脚本。
- `TrayHost.ShowFrontend` 仍启动旧 `AudioSwitch.exe --ui/--prompt`。新面板手动启动，关闭后释放进程；生产网页已嵌入 Tauri，不依赖开发服务器。
- 新桌面 EXE 为 `audio-switch-panel.exe`，目前 Tauri `bundle.active=false`。原 C# 普通构建应继续独立，不要求安装 Node 或 Rust。

## 5.1 独立候选包与清单

1. 先确定候选包的固定目录、版本来源和许可文件。包含原后台及原 8 文件、新面板和必要前端许可；根据实际构建产物核对是否还有运行依赖。不打包 Node、Rust、测试程序、用户配置、Dolby 驱动 DLL 或机器上的 WebView2 系统文件。
2. 用新脚本在唯一 staging 目录组装候选包，保留原 release.ps1 和正式附件命名／选择规则。禁止覆盖已存在的包或批量清理。
3. 建立包格式版本、固定文件名单、长度与 SHA-256 校验，验证版本匹配、缺失／多余／重复文件、路径越界和损坏包；清单校验不冒充发布签名。
4. 在隔离目录检查解压后能启动面板并正常关闭；没有后台时显示可操作提示。离线检查 WebView2 缺失的提示方案，不自动下载安装组件。

验收：候选包可复现、文件与许可齐全，破损包拒绝，原后台普通构建仍可用；日常 bin、旧更新器和音频设置未变。本项可以在无音频写入约束下推进。

## 5.2 启动入口与生命周期

1. 在测试包内接入托盘打开面板／提示，按后台所在目录定位经过验证的面板文件；参数保持固定，网页不能指定程序或任意参数。
2. 保留面板复用与前置、提示独立窗口、后台所有者退出保护；重复点击不重复创建界面。不增加常驻前端或服务。
3. 明确新面板缺失、校验失败及旧版本组合的处理办法。旧界面是否作为迁移期回退入口，在该小项开始前确定，不能静默掩盖错误。
4. 使用隔离进程测试重复启动、面板／提示退出和后台退出；需要启动真实后台时重新说明其自动音效影响，按当时授权执行。

验收：空闲只有后台，打开与关闭后的进程及内存有记录；原音频算法、自启后台身份和配置位置保持一致。

## 5.3 更新安装与修复（含 4.2b）

1. **先确定旧版升级通道，再改正式发布流程。** 旧版不能接受新文件数；可选择首次手动解压完整新包，或先发布仍符合旧格式的过渡版本。两条路线的资产命名、旧版发现行为和回退步骤需具体核对；本清单不提前承诺无缝升级。
2. 在明确的包格式下同步更新下载校验、安装事务、必要文件检查、修复来源及备份清单。保留摘要、固定 SVCL 版本、路径／链接检查和大小上限。
3. 安装前关闭本目录拥有的面板、提示及短时任务，等待对应进程退出；不结束其他目录或无关 WebView2 实例。失败恢复已尝试替换的文件，并独立核验；备份不删除。
4. 新面板接入下载进度、取消、安装确认及修复结果；沿用游戏模式和自动更新语义，未确认安装成功不能显示成功。使用隔离假程序验证锁定、断网、摘要错误、部分替换失败及恢复失败。

验收：完整候选包安装／修复／回滚均有隔离测试；中文、空格和特殊字符路径可用；用户配置和备份保留。真实自动升级另做验收，不由模拟代替。

## 5.4 发布与日常替换前验收

- 补齐第四阶段真实保存／导入恢复、Dolby 应用和取消恢复、实际设备提示、USB／蓝牙插拔、睡眠唤醒及跨屏 DPI；仅在用户允许对应副作用后执行。
- 核对完整安装、所选旧版迁移路线、同版本修复和升级失败恢复；版本、许可、说明、校验及配置保留一致。
- 分别记录后台、打开面板和关闭面板后的进程／内存，不套用参考项目的性能结论。
- 更新 README、CONFIGURATION、MANUAL-TESTS 和发行说明。包及差异先交付检查，再由用户决定发布或替换日常程序。

本轮用户要求无音频写入，因此这些实机项目仍待验；这不妨碍 5.1 的隔离打包准备，但不能据此宣布整个重构已验收或直接替换日常版本。
