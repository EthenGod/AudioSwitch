# 第三阶段：主面板真实操作

## 实施清单

- 设备切换调用现有后台路由；输入／输出按端点 ID 区分，保留通话联动规则，不在 Rust 重写音频逻辑。
- 设备抽屉读取真实音量与空间音效支持列表。驱动读取失败时保留已有字段，未知空间格式继续保留；不把示例 GUID 发给真实后台。
- 基础预设和白名单新增窄接口，仅保存 Volume / SpatialFormat / DeviceRule，由后台保留最新 Dolby 对象。对已变更的基础预设／规则拒绝覆盖，允许离线设备保存。
- “仅保存”路径不调用音频读取、切换、音效应用或 Dolby 队列；修改后的规则等待下一次正常使用时生效。
- 接入优先级、排序、询问、通话联动、主题、游戏模式、自动更新开关和开机自启。优先级／排序沿用原有即时应用语义，界面明确说明；自启仅指向真实后台路径并检查原登记值。
- Rust 只允许显式命令及严格参数类型，不开放任意请求、路径、配置导入导出、更新或进程执行。
- 新后台声明面板接口版本，并分别返回本次操作错误、已保存状态和后台告警；老后台回退只读。
- 前端和 Rust 双层防重复请求；写入超时／断线不自动重试，先读取状态确认，再允许下一次写入。后台返回部分成功时同步实际状态，不伪报完成或恢复。
- 保留浏览器纯模拟预览。桌面窗口关闭正常退出；编辑草稿不会被窗口重新聚焦时的刷新清掉。
- 验证契约、参数拒绝、仅保存、同名／离线、null／零值、Dolby 保留、重复点击、失败与超时、真实／模拟提示和窗口退出。

## 范围

只修改前端与必要 IPC 适配；Dolby 编辑器、更新／导入导出界面及发布替换留到后续阶段。不覆盖正在运行的程序、不自动提交或合并。实机音频写入与无副作用测试分开记录；没有执行的实机项目明确保留待验收。
