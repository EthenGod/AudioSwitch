# 程序图标

`AudioSwitch.ico` 使用现有 `src/AppIcon.cs` 中的蓝底白色声波 Logo，包含 16、20、24、32、40、48、64、128、256 像素的透明背景图标。

底板与声波统一以 48 单位画布的 `(24, 24)` 为中心，底板四周各留 0.5 单位。ICO 按四倍尺寸绘制再缩小，减少小尺寸笔画的采样差异；256 像素版本四边约留 3 像素，避免原底板偏向左上的问题。

`build.ps1` 用 `/win32icon` 将其嵌入 EXE，然后生成程序完整性校验值。`release.ps1` 将同一个 EXE 放入 ZIP 并复制为独立下载文件，因此两个版本都有相同图标，无需额外分发 ICO。

未来更换 Logo 时，同时更新此 ICO 与 `AppIcon.DrawMark`，保持文件图标、窗口和托盘图标一致。此目录是源码构建所需资源，应随源码提交。
