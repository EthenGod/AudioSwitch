# 声间使用指南

[返回首页](../../README.md)

本指南对应仓库当前代码。已发行版本包含的功能，以该版本的发行说明为准。

## 语言与外观

首次启动时选择语言。程序优先匹配系统首选语言，未匹配到时推荐简体中文。确认后保存选择，以后可在“应用设置 → 语言”中更改。目前提供简体中文、英语和日语。

系统设备名称和你填写的名称不会被翻译。设备类型、状态、按钮等由程序提供的文字随语言切换。语言选择独立于深浅色和界面风格。主面板尚未设置外观时使用深色。

## 设备与自动切换

在“声音设备”中切换默认输出或麦克风。打开设备设置可修改显示名称，留空恢复系统名称。相同名称的设备仍按各自的 Windows 端点 ID 区分。

在“自动切换”中拖动设备调整优先级，也可以用上下移动按钮。输出和输入分别排序。开启优先级或调整排序可能立即切换设备。关闭“同时切换通话设备”后，不更改默认通话角色。

接入规则优先于普通排序和接入询问。接受系统选择时保留 Windows 的结果；设置接入后主动切换时，会应用该设备的预设。离线设备保留其排序和预设。

“仅保存”存储设置，不立即修改音效。以后切换到该设备时再应用预设。关闭设备提示窗口会保留当时的系统选择。

## 设置与备份

唯一活动配置为 `%LOCALAPPDATA%\AudioSwitch\settings.json`。程序自动保存设置。`AudioSwitch.exe.config` 是运行环境文件，不是个人配置。

在“应用设置 → 导出备份”中保存副本。在“导入设置”中选择备份，检查摘要后确认。导入前会保留原配置的完整备份；导入本身不启动新的音频写入。无效或不受支持的备份不会替换当前设置。

导入和导出包含设备名称、排序、接入规则、预设及应用偏好。名称补全历史只保存在本机，不随备份或程序包分发。开机自启登记也是本机设置，不随备份导入。

请优先使用声间导出的备份。旧备份缺少语言字段时保留当前选择。不支持的语言或风格可以保留在配置中，界面暂时使用中文或经典风格。音量、空间音效或 Dolby 参数的“保持不变”与“关闭”含义不同。

## 浏览器面板

在应用设置中，将双击托盘图标的行为改为“在浏览器打开”。面板只在本机地址 `127.0.0.1` 提供服务。

“保持浏览器端口开放”默认关闭。开启后，关闭浏览器标签仍保留本机服务。关闭该开关后，现有标签可继续使用，最后一个标签关闭后服务会退出。退出声间后台也会释放服务。

浏览器端口留空时自动分配。输入 `1–65535` 的数字后自动保存，下次开启服务时生效。端口被占用时请换一个。不要分享浏览器面板的完整访问地址。

## 更新与文件检查

“检查更新”目前使用 GitHub，可选择仅接收正式版或包含测试版。测试版可能存在尚未解决的问题。

开启自动更新后，程序会在空闲时下载，下次启动时安装。游戏模式暂停自动更新，仍可手动检查。游戏模式也会降低后台进程优先级，并在系统支持时使用效率模式；设备接入和断开继续响应。

“文件检查”检查程序文件，并显示通过、缺失或无法读取的项目。需要修复时可下载当前版本的完整包。安装或修复前按界面提示确认。个人配置与已有备份不属于程序文件修复范围。

## Dolby 方案

Dolby 功能仅支持已适配的 DAX 组件和输出设备。遇到不受支持的组件提示时，不要绕过检查或替换驱动文件。

设备设置中的 Dolby 编辑器可以读取当前方案、保存设备方案，或立即应用到当前输出。开启“成为输出时自动应用此方案”后，方案会跟随该设备成为默认多媒体输出。没有方案的设备不会主动重置 Dolby。

“仅保存”不写入当前音效；Dolby 编辑器中的“保存并应用”仅对当前输出立即生效。关闭某项强度的开关表示保持原值，不等于将该效果关闭。驱动可能按支持的档位调整强度。

均衡器提供两种视图：

- **10 点 dB**：频率标签为 32、64、125、250、500 Hz、1、2、4、8、16 kHz，范围为 −12 至 +12 dB。
- **20 段原始值**：直接编辑驱动单位整数，这些数值不是 dB。

只查看或切换视图不会改写曲线。修改任意 10 点值后，会重新换算全部 20 段；原始曲线的中间细节可能随之变化。保存和备份始终保留 20 段值。应用失败时查看恢复结果，不要把失败提示当作已成功恢复。
