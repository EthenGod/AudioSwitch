## 言語と外観

初回起動時に言語を選びます。初期設定は「システムに合わせる」です。システムの優先言語と一致する言語を使い、一致しない場合は簡体字中国語を使います。確認すると選択が保存され、次回からは確認画面を表示しません。「アプリ設定 → 言語」でシステムに合わせるか、簡体字中国語・英語・日本語のいずれかに固定できます。

システムのデバイス名と自分で入力した名前は翻訳しません。アプリが表示するデバイスの種類、状態、ボタンなどは選択した言語に切り替わります。言語はライト・ダークモードやインターフェースのスタイルとは別の設定です。外観が未設定の場合、メインパネルはダークモードになります。

## デバイスと自動切り替え

「サウンドデバイス」で既定の出力またはマイクを切り替えます。デバイス設定で表示名を変更でき、空欄にするとシステムの名前に戻ります。同じ名前でも、Windows のエンドポイント ID により別々のデバイスとして扱います。

名前の先頭を入力すると、この PC に保存した名前の候補が薄い文字で表示されます。Tab を押すたびに次の単語を補完します。採用していない候補の部分は保存されません。

「自動切り替え」でデバイスをドラッグするか、上下移動ボタンで優先順位を変更します。出力と入力は別々に並べ替えます。優先順位の有効化や並べ替えにより、すぐにデバイスが切り替わることがあります。「通信用デバイスも切り替える」を無効にすると、既定の通信デバイスは変更しません。

接続ルールは、通常の優先順位や接続時の確認より優先されます。システムの選択を受け入れる場合は、Windows の結果を保ちます。接続時に切り替えるルールでは、そのデバイスのプリセットも適用します。オフラインのデバイスも優先順位とプリセットを保持します。

「保存のみ」は設定を保存し、音響効果をすぐには変更しません。そのデバイスに後から切り替えた際にプリセットを適用します。デバイス通知を閉じると、その時点でのシステムの選択を保ちます。

## 設定とバックアップ

有効な設定ファイルは `%LOCALAPPDATA%\AudioSwitch\settings.json` のみです。設定は自動保存されます。`AudioSwitch.exe.config` は実行環境のファイルであり、個人設定ではありません。

「アプリ設定 → バックアップをエクスポート」でコピーを保存できます。「設定をインポート」では、バックアップを選び、概要を確認してから実行します。置き換え前に、元の設定全体をバックアップします。インポート自体は新たな音声設定の書き込みを開始しません。無効または非対応のバックアップで現在の設定を置き換えることはありません。

バックアップには、デバイス名、優先順位、接続ルール、プリセット、アプリ設定が含まれます。名前の補完履歴は各 PC のみに保存し、バックアップや配布パッケージには含めません。Windows の自動起動登録も PC 固有の設定であり、インポートされません。

AudioSwitch からエクスポートしたバックアップを使用してください。言語の項目がない古いバックアップをインポートしても、現在の言語を保ちます。非対応の言語やスタイルは設定に保持し、表示だけを一時的に中国語またはクラシックに戻します。音量、空間サウンド、Dolby の「変更しない」は「オフ」とは異なります。

## ブラウザーパネル

設定で、トレイアイコンのダブルクリック時の動作を「ブラウザーで開く」に変更します。パネルはローカルアドレス `127.0.0.1` でのみ提供します。

「ブラウザーポートを開いたままにする」は既定では無効です。有効にすると、タブを閉じてもローカルサービスが動作し続けます。無効に戻しても開いているタブは使えますが、最後のタブを閉じるとサービスが終了します。AudioSwitch のバックグラウンド処理を終了した場合も、ブラウザーサービスを終了します。

ポート欄を空にすると自動割り当てになります。`1–65535` の数値を入力すると自動保存され、次にサービスを開始するときに反映されます。使用中のポートは別の番号に変更してください。ブラウザーパネルの完全なアクセス URL を共有しないでください。

## 更新とファイルチェック

「更新を確認」では現在 GitHub を使用します。安定版のみ、またはテスト版を含めるかを選べます。テスト版には未解決の問題が残っている場合があります。

自動更新が有効な場合、PC がアイドル状態のときにダウンロードし、次回起動時にインストールします。ゲームモードでは自動更新を一時停止しますが、手動確認は可能です。また、バックグラウンドプロセスの優先度を下げ、対応するシステムでは効率モードを使います。デバイスの接続・切断への応答は続きます。

「ファイルを確認」では、プログラムファイルの正常、欠落、読み取り不可を表示します。修復が必要な場合は、現在のバージョンの完全なパッケージをダウンロードできます。インストールや修復前に、画面の確認操作を行ってください。個人設定と既存のバックアップは、プログラムファイルの修復対象ではありません。

## Dolby プロファイル

Dolby 機能には、対応する DAX コンポーネントと出力デバイスが必要です。コンポーネントが非対応と表示された場合、チェックを回避したり、ドライバーファイルを置き換えたりしないでください。

デバイス設定の Dolby エディターでは、現在のプロファイルの読み取り、デバイス用プロファイルの保存、現在の出力への適用ができます。「出力に選ばれたときに適用」を有効にすると、そのデバイスが既定のマルチメディア出力になった際に適用します。プロファイルのないデバイスでは、Dolby をリセットしません。

「保存のみ」は現在の音響効果に書き込みません。Dolby エディターの「保存して適用」は、現在の出力にのみ即時適用します。強度の指定をオフにすると元の値を保ち、効果自体をオフにするわけではありません。ドライバーが対応する段階に合わせて強度を調整する場合があります。

イコライザーには 2 つの表示があります。

- **10 ポイント dB**：周波数ラベルは 32、64、125、250、500 Hz、1、2、4、8、16 kHz で、範囲は −12 ～ +12 dB です。
- **20 バンドの生の値**：ドライバーの整数値を直接編集します。この値は dB ではありません。

表示の切り替えや閲覧だけではカーブを書き換えません。10 点のいずれかを編集すると全 20 バンドを再計算するため、元のカーブの中間部分が変わる場合があります。保存とバックアップでは常に 20 バンドの値を保持します。適用に失敗した場合は復元結果を確認してください。失敗メッセージが出たことだけでは、復元成功を意味しません。
